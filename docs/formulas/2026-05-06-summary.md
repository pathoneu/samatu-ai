## Critical defaults (LT)
- Ceiling height: **2.82 m** (modern post-2010); 2.50 m (Soviet-era)
- Door opening: **0.9 × 2.05 m = 1.85 m²**
- Window opening: **1.2 × 1.5 m = 1.80 m²** (NOT 1.40 m² — that was a US-default bug, fixed)
- Wall thickness: 0.20 m block / 0.10 m GKP partition / 0.30–0.50 m insulated exterior
- Bathroom tile height: 2.0 m (configurable up to ceiling for premium)
- VAT: **21% PVM** always; renovation = reverse VAT

## Where assumptions diverge — surface in UI
1. **Opening deduction standard**: LT (1.0 m², always reveal) vs NRM2 (>3.0 m² reveal) vs VOB DIN 18363 (>2.5 m²) — `Prielaidos` toggle.
2. **GKP "tikslus vs praktinis"**: deduct openings or treat cutouts as waste — Setup Wizard toggle (not yet exposed).
3. **Q-level defaults**: Q2 for matte paint, Q3 for semi-gloss, Q4 for gloss/raking-light — surface warning if mismatched.
4. **Tile waste 8% vs 10%**: bump default to 10%; 8% only for simple rectangles.
5. **Cornice waste 5% vs 10%**: bump default to 10% for mitred.
6. **Inside vs outside corner bead**: split positions to avoid metal-bead over-spec by ~70%.
7. **Hidroizoliacija**: ALWAYS emit a position for vonia/wc/san even if spec silent — it's a STR 2.04.01 mandate and the most-forgotten item.

## Validation checks (run before presenting)
- Paintable walls / floor area: 2.5–4× (reduce to 2.0× for >40 m² open plan)
- Ceiling area ≈ floor area for flat; > floor for sloped (use slope_factor)
- Baseboard ≈ perimeter − 0.85 m × n_doors
- Paint ≈ **0.20 L/m²** (NOT 0.22 — that's 2.0×; we use 1.8×)
- GKP screws: 10/m² (flag if <8 or >15)
- Tile adhesive: 3.5 kg/m² (flag if <2 or >8)
- Primer: 0.15–0.20 L/m² (flag if <0.10 or >0.30)
