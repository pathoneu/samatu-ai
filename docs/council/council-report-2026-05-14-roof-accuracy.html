Blind Spots the Council Caught (in peer review)

  • Inter-page consistency is unmeasured. Drawings round to 100mm and disagree across sheets. Before claiming an accuracy target, measure variance.
  • Waste factors swamp extraction error. Roofing 5-10% waste vs 2% extraction precision is false precision.
  • The flywheel needs infrastructure that doesn't exist. Storing structured corrections + retrieval/few-shot prompting is its own project.
  • Ground truth is contractor opinion, not truth. Same trap CLAUDE.md names for detector_bench/.
  • Roofers rubber-stamp under time pressure. HITL only produces clean signal if UI forces engagement (page crop, anomaly highlight, two-click confirm on flagged dims).
