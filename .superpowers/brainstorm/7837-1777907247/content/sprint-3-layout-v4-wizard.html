Wizard'o detalės

  • Trigger — top-bar mygtukas 🟡 3 → arba kategorijos antraštės klikinant ant `🟡 N` skaičiuko (filter'as → wizard'as)
  • Layout — bottom panel ~140px, virš canvas. UI'aus likusios dalys (rail, KŽ panel) paslepiama blur'inant (opacity 0.4-0.55) — fokusas ant klausimo. Canvas auto-zoom'ina į einamąjį polygon'ą.
  • Question struktūra: "🟡 Reikia patikrinti · [Skyrius]" antraštė + "Patalpoje X rastas Y plotas Z m²" pagrindinis tekstas + šaltinio paaiškinimas su "Detaliau" link'u (atveria provenance popover'ą — kaip Phase C-2).
  • Mygtukai:
    • Taip ✓ (mėlynas, primary) — patvirtina, wizard pereina į next step. Pozicija pažymima kaip "checked" bet NE lock'inama (default behavior — gali AI vėl perskaičiuoti). Shift+Taip = + lock 🔒.
    • Pataisyti (cream amber) — atitinkama gestūra triggerinasi. Jei dispute = skaičius → G7 inline editor atsidaro tiesiai bottom panel'e (input lauke, ne canvas'e). Jei dispute = polygon → canvas'e atsiranda G1 click hint. Po taisymo wizard auto-advance į next.
    • Praleisti → (subtle text link) — pažymi kaip skipped, pereina toliau. Skipped pozicijos lieka 🟡, bet wizard'as jas peršoka per kitą "Patikrinti" click'ą.
  • Progress bar viršuje (1/3 + 3 dot'ai) — vizualus indikatorius kiek liko
  • Užbaigus — bottom panel pasikeičia į: "Visi 3 patikrinti! Σ 12 458 € + 21% PVM = 15 074 €. [Eksportuoti KŽ] [Grįžti į workspace]". Top bar mygtukas dingsta arba pakeičia tekstą į ✓ Patikrinta.
  • Vidury uždaryti — ✕ mygtukas top-right'e arba Esc. Likusios skipped pozicijos lieka 🟡, "Patikrinti" mygtukas top-bar'e rodo likusių skaičių.

Klausimai prieš rašant spec'ą

  1. "Taip ✓" default behavior — (a) lock'inti 🔒 (saugu, rigid) ar (b) palikti laisva (lankstu, AI gali perskaičiuoti). Mano siūlymas: (b) default + Shift+Taip = lock. Sutinki?
  2. "Pataisyti" UI surface — atsidaro tiesiog bottom panel'ėje (G7 inline editor vietoj klausimo) ar canvas'e (G1 click cursor)? Mano siūlymas: priklauso nuo dispute_type — skaičius → bottom panel input, polygon → canvas G1 cursor.
  3. Wizard'as gali rodyti tik 🟡 + 🔴 ar pridėti opciją "patikrinti viską" (ir 🟢) for paranoid users? Mano siūlymas: default tik 🟡 + 🔴. Settings → galima įjungti "viską peržiūrėti" jei nori.
